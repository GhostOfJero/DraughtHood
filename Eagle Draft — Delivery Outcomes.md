# DraughtHood — Delivery Outcomes

- [x] **Playable Nigerian Draft game:** “Build a simple Nigerian Draft board game” and “Eagle Draft should be the game.” Implement Nigerian 10×10 mirrored draughts with 20 seeds per side, legal forward movement, backward captures, mandatory captures, selectable capture routes—including distinct routes to the same landing square—king promotion and flying-king play, turn handling, win detection, and a working match against a computer opponent.
- [x] **Difficulty and challenge play:** “different categories of difficult and challenges.” Provide clearly labeled CPU difficulty categories and distinct playable challenge scenarios with objectives, feedback and locally recorded completion.
- [x] **Nigerian cultural flavor, smooth animations and UI:** “with culture flavors, ... smooth animations and UI.” Apply a considered Nigerian game-club identity with legible phone-first board/screen design, touch-friendly controls, and understandable turn/move/challenge/outcome status.
- [x] **Mobile and APK sideload readiness:** “APK side loading app preferred.” Deliver the fixed Expo/React Native mobile project with offline local saves, consistent Android launcher/adaptive/splash branding, preserved package identifiers, and an Android APK build configuration/handoff suitable for sideloading.
- [x] **Game controls and local continuity:** Include new game, restart, pause, undo where permitted, and sound settings; save and resume game progress and local records without requiring network access.
- [x] **Multiplayer mode:** “Add a multiplayer mode or AI difficulty levels to Eagle Draft.” The AI difficulty levels already exist; add a two-person, same-device pass-and-play mode while preserving AI matches. Provide a separate lobby launch action, alternate turns between Player 1 (bottom/near side) and Player 2 (top/far side), conceal the board behind a pass-to-next-player handoff until they tap Ready, display the active player and correct winner, retain legal move/capture/promotion/undo/restart behavior, and save mode and turn state for offline resumption. Do not require an account, network, or realtime service.
- [x] **DraughtHood rebrand:** “rename the game to DraughtHood.” Replace Eagle Draft as the visible app/game name across the lobby, match/results, rules and native display name; retain the established Eagle mascot/launcher mark and preserve existing bundle IDs, scheme and app slug.
- [x] **Visual effects, click animations and crowns:** “Add more visual effects to the game, improve click animations which is at moment too crude. the crowns need a much design to pop on the board.” Replace crude tap feedback with purposeful press/selection/landing/capture/promotion/result effects, and give crowns a clear, detailed, high-contrast design that stands out on both player colors without obscuring board readability.
- [x] **Incremental challenge hurdles:** “Add incremental challenge hurdles.” Arrange challenges as an ordered, progressively harder ladder: show stage number and locked/open/cleared state, unlock each next hurdle when the previous one is cleared, explain locks, and preserve already-recorded progress.
- [x] **Per-match statistics report:** “game statics report for each game play.” For each finished game, calculate and display a report with outcome, game mode, difficulty or challenge, duration, turns/moves, captures by both sides, crowns earned, and remaining seeds; save reports locally so they can be reviewed later from Records.
- [ ] **Global leaderboard:** “Add a global leaderboard ... to DraughtHood.” Show ranked Classic-vs-CPU best scores from the shared service; disclose that posted nickname and score are public; never upload automatically; only send a score after the player explicitly submits their displayed nickname and points. Store no account or personal details, and do not include local pass-and-play or challenge matches in the ranked table.
- [ ] **Local high-score saving:** “... and local high-score saving feature ...” Calculate a clearly explained score for a Classic win, save the best score and associated report offline on-device, and display it even while the leaderboard is unavailable. Migrate existing local profiles without losing reports, settings, or active games.
- [ ] **Checkmate, draw declaration and restart:** “And in the event of checkmate, declaration of draw game and restart.” Clearly announce a game-ending win when all opposing seeds are captured or the opponent has no legal move, allow players to confirm a draw declaration during a live match and record a draw with no winner, and offer a clean restart after a finished game using the same mode, difficulty and challenge while preserving records.
